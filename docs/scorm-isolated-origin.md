# Isolated SCORM content delivery

Configure `SCORM_CONTENT_ORIGIN` to an **exact HTTPS origin** distinct from every LMS tenant host (for example `https://scorm.example.com`). Development/test default: `https://scorm.lms.localhost`. Set DNS and a valid TLS certificate for that host. Route **only GET/HEAD `/api/scorm/delivery/*`** to the API, preserving the Host header; drop upstream `Cookie`/`Authorization` and downstream `Set-Cookie`. All other paths and methods must return 404. `apps/reverse-proxy/Caddyfile` provides the local example; reproduce that isolated vhost in production. Do not expose the API directly through this hostname by a second ingress.

`SCORM_CONTENT_ALLOWED_CONNECT_ORIGINS` accepts comma-separated exact HTTPS origins (optional ports). `SCORM_CONTENT_ENFORCE_CONNECT_SRC=true` enforces `'self'` plus these origins; default `false` only reports the connection policy. The script, image, media and style restrictions are **report-only**. Native form submission is blocked; script-driven form handlers and modal resume dialogs work. The LMS must have a trusted tenant HTTPS host in the tenant table, not merely an HTTP fallback. Ensure content-host requests bypass ordinary tenant-host resolution and are scoped only after a Redis grant is validated.

Redis must be shared across API instances and available. Grants last at most 15 minutes and are renewed from the authenticated LMS page every five minutes; logout revokes the issuing credential digest. This branch's auth system predates #163's per-session Redis registry: individual access-token refresh/session replacement and MFA policy changes cannot be revalidated against that registry until #163 is ported. Do not treat this as complete #163 session assurance. Tokens in URLs can appear in access logs; redact `/api/scorm/delivery/<token>/...`, disable caching, and do not send them to third-party analytics. Restart API after configuration changes. Retest on the deployed proxy, including wrong Host, 404 outside delivery, no forwarded credentials, CSP behavior, and browser progress persistence.
