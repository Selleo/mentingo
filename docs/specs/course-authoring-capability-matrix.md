# What the course-generation assistant can do

The assistant works on the course you currently have open. It can read that course, use your materials, research a topic and create or edit its content.

## Read and research

| Task                                                 | Can it do it?                    | Example / limitation                                                                                              |
| ---------------------------------------------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Read the current course details and outline          | Yes                              | “What does this course cover?”                                                                                    |
| Read existing lesson content                         | Yes                              | “Read lesson 2 and tell me what is missing.” Includes theory, quiz questions and AI Mentor setup.                 |
| Read uploaded documents                              | Yes                              | “Build a course from these four PDFs.” Accepts PDF, DOCX, TXT and Markdown. Uploads must finish processing first. |
| Find information in uploaded documents               | Yes                              | “What does the manual say about cleaning this pump?”                                                              |
| Understand scanned pages and diagrams                | When image reading is configured | It should tell you when a page or image could not be read.                                                        |
| Search the public web                                | With your permission             | “Research the latest product information.” Enable web search or answer the permission question.                   |
| Read a public link you provide                       | With your permission             | Uses the same web access setting as search.                                                                       |
| Search other courses in Mentingo                     | No                               | This assistant only has access to the current course.                                                             |
| Read private websites or files you have not attached | No                               | It cannot sign in to websites or browse your drive.                                                               |

## Create and edit

| Task                                                | Can it do it?                       | Example / limitation                                                                                              |
| --------------------------------------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Plan a course                                       | Yes                                 | Clarifies audience, learning goals and length when needed, then proposes chapters and lessons.                    |
| Write or improve theory lessons                     | Yes                                 | “Explain this more simply.” Content lessons contain theory; exercises and assessments go in quizzes or AI Mentor. |
| Create or edit quizzes                              | Yes                                 | “Add a quiz covering the first chapter.”                                                                          |
| Create or edit AI Mentor lessons                    | Yes                                 | “Add a roleplay where a salesperson advises a customer.”                                                          |
| Add, rename, reorder or delete chapters and lessons | Yes                                 | “Add an AI Mentor lesson to each chapter.”                                                                        |
| Change part of an existing lesson                   | Yes                                 | “Rewrite the introduction and keep the rest.”                                                                     |
| Translate course content                            | Yes                                 | “Translate this lesson into Polish.”                                                                              |
| Change the course title and description             | Yes                                 | “Make the description shorter.”                                                                                   |
| Change course settings                              | Some settings                       | Lesson order enforcement, quiz feedback, video completion tracking and supported certificate settings.            |
| Add generated illustrations                         | When image generation is configured | Depends on the available image provider.                                                                          |
| Generate videos, podcasts or SCORM packages         | No                                  | These are not course-generation actions.                                                                          |
| Apply its changes to the current course             | Yes                                 | After your approval, or automatically in Autopilot.                                                               |
| Publish the course or change who can access it      | No                                  | Use the regular course controls.                                                                                  |
| Assign the course to learners or view their results | No                                  | Use the regular assignment and reporting features.                                                                |

## What Autopilot changes

Both modes can do the same tasks. Autopilot only changes who approves the work.

| Step                                      | Review changes       | Autopilot            |
| ----------------------------------------- | -------------------- | -------------------- |
| Clarify audience, goals and course length | Asks you when needed | Asks you when needed |
| Ask for missing information or web access | Asks you             | Asks you             |
| Approve the outline                       | You                  | Automatic            |
| Approve and apply completed changes       | You                  | Automatic            |

You can stop generation in either mode. Choosing Autopilot does not give the assistant additional access or permission to publish the course.
